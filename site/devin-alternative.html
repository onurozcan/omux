Devin alternative: run your own agents on your Mac, in the open

Devin from Cognition is an autonomous software engineer. You assign it a task from chat, Slack, Linear, Jira or GitHub, it works on its own cloud machine and comes back with a pull request. Since the Windsurf acquisition it also ships Devin Desktop, an editor, with a free tier, paid plans and team seats.

omux is the hands-on end of the spectrum. The Claude Code and Codex sessions run on your Mac, in your checkout, and you watch, answer and steer them in a sidebar that shows which one needs you. Nothing leaves your machine except what the agents themselves send. This page is for deciding how much of the loop you want to hold.

See omux in 37 seconds

→ Pick Devin if

  • You want to hand off tasks from Slack or an issue tracker and get a pull request back without watching.
  • You want agents on cloud machines that keep going when your laptop is closed.
  • Your team wants one managed platform with seats, admin controls and analytics.

★ Pick omux if

  • You want to steer the work as it happens, in the terminal, with the diff beside the agent.
  • You already pay for Claude Code or Codex and don't want a second platform or account.
  • You want the code to stay on your machine, and the tool to be free and open source.

What omux does for every session

  • Projects with sessions under them, in a sidebar
  • Shows whether each agent is working, needs you or is done
  • Allow or Deny an agent's permission request without switching to it
  • Lists a session's subagents and opens their transcripts
  • Resumes each Claude Code and Codex conversation after a relaunch
  • Git worktree per session, with pull request status and merge
  • Files, Changes (diff with review notes) and Browser panels
  • Claude and Codex plan usage limits in the sidebar
  • Split panes: up to six sessions side by side per project, layouts saved
  • An omux command line: list, status, send, new, close and wait on sessions
  • macOS notifications with sound

Questions

Is omux an autonomous engineer?

No. It's the window you run your own agents in. Claude Code and Codex do the work; omux shows their status, permissions, subagents, diffs and pull requests, and keeps every session's conversation across relaunches.

Can I use omux and Devin together?

Yes. Many people hand well-specified tasks to a cloud agent and keep interactive work local. They don't overlap.

Does omux upload my code anywhere?

No. omux has no server and no telemetry. The agents talk to their own providers as they would in any terminal.
